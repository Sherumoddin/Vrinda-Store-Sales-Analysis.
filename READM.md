# Vrinda Store Sales Analysis | Power BI Dashboard

## Project Overview

The Vrinda Store Sales Analysis project is an interactive Power BI dashboard designed to analyze store sales performance and understand customer purchasing behavior.

The dashboard provides insights into sales trends, customer demographics, order channels, product categories, and geographical sales distribution.

The objective is to transform raw sales data into meaningful business insights that can support better decision-making.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Cleaning & Transformation

## Dashboard Features

### 1. Sales Performance Analysis
- Total Sales Analysis
- Total Orders
- Total Quantity Sold
- Quarterly Sales Trends

### 2. Customer Analysis
- Gender-wise Sales Distribution
- Age Group-wise Sales Analysis
- Customer Purchasing Patterns

### 3. Product Analysis
- Category-wise Sales Performance
- Quantity Sold by Product Category
- Product Performance Insights

### 4. Sales Channel Analysis
- Sales Distribution by Channel
- Order Status Analysis
- Channel Performance Comparison

### 5. Geographical Analysis
- State-wise Sales Performance
- City-wise Sales Distribution
- Regional Sales Insights

## Key Business Questions

This dashboard helps answer the following business questions:

1. What is the overall sales performance of Vrinda Store?
2. Which customer gender contributes more to sales?
3. Which age group generates higher sales?
4. Which product categories perform better?
5. Which sales channels contribute significantly to revenue?
6. How do sales vary across different quarters?
7. Which states and cities generate higher sales?
8. What is the distribution of order statuses?
